# Reinforcement Rot 研究计划（内部文档）

## 故事线

> 让多智能体系统越用越好的机制，和让它无报错空转到死的机制，是同一个机制；
> 我们命名它、给它理论、造仪器测量它、用干预证明它、用蒸发修复它。

- 现象名：**Reinforcement Rot**
- 机制名：reinforcement without evaporation（无蒸发强化）
- 目标会议：ICLR（定律层野心：理论预言 + 实验验证的闭环）

## 现象的五条判据（每条对应一个测量）

1. 周期性：状态-动作序列出现重复周期 → cycle_rate（loop-erased 分解）
2. 零进展：周期内目标距离不缩短 → excess_over_shortest（成功 episode）/ budget_exhaustion（失败 episode，分开报告）
3. 集体性：≥2 个 agent **同轮**收敛到同一周期 → mill_rate（分组键 maze_seed × round × canonical_loop，≥2 个不同 agent_id；同 agent 跨轮自转只计入 individual_cycle_rate）
4. 持久性：逃逸概率随轮数递减 → escape_time（首个连续重复 ≥2 次的周期段：进入 = 首次进入该段，逃逸 = 首次离开该段全部细胞；分前/后半轮报告 escape_rate）
5. 静默性：全程无非法动作、无报错 → death_rate + 合法性审计

## 设计定律

**强化算子与蒸发算子必须作用在同一状态变量上、互为对偶**。L3 中该状态变量是
(cell, direction) 条目的权重；自然语言文本是挂在权重上的证据（保留全部历史，
展示最新文本 + 背书 agent 数）。单独改变检索排序（recency 偏置）不算蒸发。

## 参数语义约定（2026-08 冻结）

- **λ（L2/L1）= 逐 tick 信息素保留率**；L1 的 κ = −ln(λ)。
- **L3 蒸发是逐 episode 的**；配置按可解释性更好的**逐轮保留率**给出：
  lam_episode = round_retention^(1/n_agents)。
- 跨层映射只在**机制层面**（带的存在性、双边界机制），不声称 λ 数值一一对应。
- **δ（L3）必须为偶数**：二分网格上同两端点的两条路径长度差必为偶数
  （对应 L2 的 L1 = L0 + 2δ）。L3 剂量网格 δ ∈ {2, 4, 6}。
- **top_k 只是候选集截断**，不等于 β→∞；每个模型的 β_eff 由
  `llm/calib_beta.py` 实测（softmax 选择模型拟合 + bootstrap CI）。

## 三个可检验预言

- T1（方差）：λ=1 时跨种子结局方差大；λ < λ_c 时方差塌缩 ✅（L2 已验证）
- T2（杀手预言）：δ 越小的绕路越危险 ✅（L2 已验证）
- T3（规模）：群体越大锁定越快 ✅（L2 N 扫描：N=2 峰值 λ=0.99，N=8 峰值 λ=0.95，双边界反向移动；L3 待验证）

## L1/L2 已确立结果

- 磨盘带 λ ∈ [0.93, 0.97]，双边界：下边界=磨盘存活，上边界=成形赛跑
- 磨盘是亚稳态：临界质量分界线，之上自治、之下雪崩
- 寿命曲线 τ_mill(λ, β)：β=1.5 恒 ~100 tick（无法存活）；β≥2 随 λ 增长
  （2026-08 以正确 κ 重跑，定性结论不变）
