# Reinforcement Rot 研究计划（内部文档）

## 故事线

> 让多智能体系统越用越好的机制，和让它无报错空转到死的机制，是同一个机制；
> 我们命名它、给它理论、造仪器测量它、用干预证明它、用蒸发修复它。

- 现象名：**Reinforcement Rot**
- 机制名：reinforcement without evaporation（无蒸发强化）
- 目标会议：ICLR（定律层野心：理论预言 + 实验验证的闭环）

## 现象的五条判据（每条对应一个测量）

1. 周期性：状态-动作序列出现重复周期 → cycle_rate
2. 零进展：周期内目标距离不缩短 → excess_steps（对植入最短路）
3. 集体性：≥2 个 agent 收敛到同一周期 → mill_rate（区别于单 agent 卡壳）
4. 持久性：逃逸概率随轮数递减 → escape_time
5. 静默性：全程无非法动作、无报错、常规指标不报警 → death_rate + 合法性审计

## 设计定律

**强化算子与蒸发算子必须作用在同一状态变量上、互为对偶**（写入↔条目死亡，投票↔强度衰减 ×λ）。
单独改变检索排序（recency 偏置）不算强化也无法配对，不在理论管辖范围内。

## 三个可检验预言

- T1（方差）：λ=1 时跨种子结局方差大；λ < λ_c 时方差塌缩 ✅（L2 已验证）
- T2（杀手预言）：δ 越小的绕路越危险——最危险的是"局部完全合理"的微小偏移 ✅（L2 已验证）
- T3（规模）：群体越大锁定越快（待 L2 补 N 扫描 + L3 验证）

## L1/L2 已确立结果

- 磨盘带 λ ∈ [0.93, 0.97]，双边界：下边界=磨盘存活（寿命 τ_mill 超过观察窗），上边界=成形赛跑（干道锁定先于环的临界质量）
- 磨盘是亚稳态：临界质量分界线，之上自治、之下雪崩（人少→味淡→逃更快）
- 寿命曲线 τ_mill(λ, β)：β=1.5 恒 ~100 tick（磨盘无法存活）；β≥2 随 λ 增长并趋于发散
- 临界质量标度：n_c ∝ κ^(1/β)（可检验的定量推论）
- β 的 LLM 对应物 = top-k 检索的尖锐度：top-k 截断相当于 β→∞，现实 MAS 天然坐在危险端

## LLM 层实验矩阵

固定配置：15×15 迷宫族，K=4 条植入宏路线（最短路 + δ=1/3/6 绕路 + 1 条闭环走廊），
最短路 ≥30 步；4 solver 错峰入场 + 1 reviewer；top-6 检索；步数上限 120；
每轮 = 4 训练迷宫（可写）→ reviewer 巩固 → 12 heldout（只读）；T=6 轮。确认性实验 8–10 seeds。

| 实验 | 内容 | 验证 | 防的审稿攻击 |
|---|---|---|---|
| B1 | 无记忆能力基线（门槛：成功率 85–90%） | — | "模型太菜" |
| B2 | 现象存在性：无记忆 / 私有记忆 / 共享+LLM 评判写入 | 存在性 | "现象不存在" |
| B3 | 扰动注入 δ∈{1,3,6} 剂量-响应 + 反向注入（好经验） | T2 + 内容盲性 | "没证明微小扰动致病" |
| B4 | 蒸发 λ∈{1, 0.97, 0.95, 0.9, 0.8} 剂量-响应 | λ_c + T1 + 权衡曲线 | "蒸发只是调参" |
| B5 | 写入规则消融：LLM 评判全量 / 仅成功 / 仅高效成功 | 病的入口 | "改写入规则就行" |
| B6 | 群体规模 N∈{1,2,4,8} | T3 | "单 agent 也一样" |
| B7 | 长视野 T=20 两臂 | T4 持久性 | "会自愈" |
| C1 | 跨模型 probe（闭源前沿 + 异家族开源 + reviewer 强弱消融） | 边界 | "模型 artifact" |
| C2 | 真实框架审计（LangGraph 共享 store，只报机制前兆） | 生态效度 | "玩具环境" |
| C3 | 代码修复循环（暂定，视进度预算） | 载体泛化 | — |

## 统计方案

种子级混合效应模型（seed 随机截距）为主推断；配对 bootstrap CI + 逐种子符号检验为辅。
所有 B 段实验预注册（假设/端点/门槛冻结 hash），阴性结果进 append-only 日志。

## 模型计划

主模型：DeepSeek-V3 级开源（固定端点、便宜、可复现）；B1 预实验标定迷宫难度。
probe：闭源前沿 ×1 + 异家族开源 ×1；reviewer 强弱消融。
